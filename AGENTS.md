# PROJECT INSTRUCTIONS: ROAST & ROOT

## ROLE
Act as a Senior UI/UX Designer, Art Director, and Senior Frontend Engineer.

## PROJECT
Build a premium coffee shop and local roastery landing page for Cimahi, West Java.

Brand: Roast & Root  
Tagline: Good Coffee. Good Company.

Target audience:
- Students and university students.
- Remote workers.
- Office workers.
- Local coffee communities.
- Specialty coffee enthusiasts.

## DESIGN DIRECTION
Style: Modern Heritage Coffee House.
Visual direction: Premium Editorial + Modern Asymmetric Layout.

The website must feel premium, warm, elegant, modern, and distinctive.

Avoid:
- Generic AI-generated website appearance.
- Generic SaaS layouts.
- Excessive rounded cards.
- Excessive gradients.
- Plain and boring sections.
- Inconsistent spacing.

## COLOR PALETTE

- Espresso Brown: #4A2C24
- Roasted Coffee: #76513D
- Vintage Gold: #C6A15B
- Burgundy: #722F3D
- Deep Maroon: #591D2A
- Cream Latte: #F3EBDD

Cream is the primary background.
Brown establishes brand identity.
Gold provides premium details.
Burgundy and maroon highlight important elements.

## TYPOGRAPHY

- Playfair Display: Headlines.
- Cormorant Garamond: Editorial accents.
- DM Sans: Body text and navigation.

## PAGE STRUCTURE

1. Navbar
2. Hero Section

4. Signature Menu

8. Testimonials
9. Footer

- Framer Motion.
- Lucide React.

Analyze the existing project before selecting or changing technologies.

## FUNCTIONAL REQUIREMENTS

- Responsive desktop, tablet, and mobile.
- Sticky navbar.
- Working mobile navigation.
- Smooth scrolling.
- Functional menu category filters.
- WhatsApp contact button.
- Google Maps integration when an address is provided.
- Subtle animations.
- Hover interactions.
- SEO metadata.
- Semantic HTML.
- Accessible buttons and images.

## CODE QUALITY

- Use modular components.
- Separate data from UI.
- Keep code clean and maintainable.
- Avoid unnecessary dependencies.
- Avoid duplicated code.
- Preserve existing project functionality.

## DEVELOPMENT RULES

1. Inspect the project before editing.
2. Create an implementation plan.
3. Implement the complete landing page.
4. Run the application.
5. Check build errors and runtime errors.
6. Test responsive layouts.
7. Fix discovered bugs.
8. Never stop after creating only the hero section.
9. Do not ask for approval for minor technical decisions.

## FINAL GOAL

Deliver a complete, visually distinctive, premium coffee shop landing page with consistent branding, functional interactions, responsive layouts, and maintainable code.
